## AULA06 — Spark ML e Machine Learning

A **AULA06** amplia os conteúdos trabalhados nas aulas anteriores, integrando **Machine Learning ao processamento distribuído com Apache Spark**.

Os laboratórios utilizam dados sintéticos e pipelines organizados em camadas, permitindo estudar diferentes técnicas de Machine Learning dentro do mesmo ambiente de processamento.

A aula aborda:

- Aprendizado supervisionado.
- Aprendizado não supervisionado.
- Classificação.
- Regressão.
- Clusterização com K-Means.
- Redução de dimensionalidade com PCA.
- Detecção de fraude.
- Classificação de sentimentos.
- Sistemas de recomendação.
- Manutenção preditiva.
- Avaliação de modelos.
- Validação cruzada.
- Ajuste de hiperparâmetros.
